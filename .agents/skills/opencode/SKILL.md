# OpenCode Protocol

Autonomous engineering framework for professional full-stack development.

## Core Principles

1. **End-to-End Integration:** Always ensure the entire stack (Frontend, Backend API, Database) is connected, tested, and actively communicating over real protocols.
2. **Modular Directory Structure:** Keep frontend, backend, database schemas, and documentation clearly segregated with explicit boundary contracts.
3. **Rigorous Build Verification:** Verify compilation (`npm run build`, `pytest`, `tsc`) with zero errors after every modification.
4. **Production Readiness:** Every endpoint, service, and database interaction must have proper error handling, schema typing, and graceful fallbacks.
