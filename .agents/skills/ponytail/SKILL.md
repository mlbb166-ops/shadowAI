# Ponytail Protocol (YAGNI & Minimal Implementation)

"He says nothing. He writes one line. It works."

## Core Rules

1. **You Aren't Gonna Need It (YAGNI):** Never build for hypothetical future edge cases that haven't been requested. Solve the exact problem in the simplest reliable way.
2. **Eliminate Boilerplate:** Do not create wrappers around wrappers or unnecessary helper files when standard language/library features already solve the problem.
3. **Keep Code Lean & Maintainable:** Fewer lines of code means fewer bugs. Prioritize clear, direct implementation over nested architectural patterns.
4. **Preserve Robustness:** Never sacrifice correctness or safety for brevity. Keep error handling, schema validation, and database integrity solid.
